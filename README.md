# Grand Cherokee Parts Hub

Create a modern, extremely user-friendly e-commerce marketplace for selling spare parts and accessories ONLY for Jeep Grand Cherokee.

REFERENCE WEBSITES:

- eBay:

https://www.ebay.com/b/Laptops-Netbooks/175672/bn_1648276

- AUTODOC:

https://www.autodoc.parts/

Use these websites only as UX inspiration. DO NOT copy their branding, exact design, layout, colors, or components.

==================================================

PROJECT

==================================================

Build a specialized online marketplace dedicated exclusively to:

JEEP GRAND CHEROKEE

The website should sell:

- Engine parts

- Transmission parts

- Brake parts

- Suspension parts

- Electrical parts

- Body parts

- Interior parts

- Exterior parts

- Lighting

- Filters

- Cooling system parts

- Exhaust parts

- Steering parts

- Wheels & tires

- Accessories

- Used parts

- New parts

- OEM parts

- Aftermarket parts

The website must be extremely easy to understand.

IMPORTANT:

This is NOT a general car-parts website.

The entire experience must be designed around Jeep Grand Cherokee.
